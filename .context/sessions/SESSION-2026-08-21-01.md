- pinned the default official RustDesk Server image to `ghcr.io/rustdesk/rustdesk-server:1.1.16`;
- changed Release Please chart version target and OCI publication paths;
- updated CI to lint/template the full chart and publish web snapshots under the new prefix;
- removed the old web-only chart.
